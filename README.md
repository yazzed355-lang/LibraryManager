## Library Manager

A simple console application for managing books in a library.

### Features
- Add a new book
- View all books
- Search books by title or author
- Borrow a book
- Return a book
- Exit the program

### Run the project
1. Open the project folder in a terminal.
2. Run:

```bash
dotnet run
```

### Project structure
- `Program.cs` – contains the menu and application flow
- `Book.cs` – defines the `Book` model
- `LibraryException.cs` – custom exception for validation errors

### Notes
This project is a small practice example for C# and basic console app logic.
